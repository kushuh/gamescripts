# Gamescripts

Scripts I made locally to track progress for achievement hunting. 

Games tend to hide some progress information, which makes tracking achievements tedious. When it happens, I'll use some AI to retroengineer the save files, and extract the information I need into simple shell scripts. This repository is a collection of those files, mainly for posterity (since I will delete the local versions once I finish the game they were built for).

# Disclaimer

Those are **vibecoded scripts** I use to check progress information hidden in save files.

Retro-engineering was performed on **distributed files** alone, no proprietary source code from unauthorized sources has ever been used.
